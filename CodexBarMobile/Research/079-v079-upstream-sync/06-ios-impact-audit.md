## Mac 专属与明确边界

- iOS 不管理 provider credential、claude-swap/tcr 切换、HTTP server 和 CLI opt-in；这类操作要求本地进程/凭证，不属于 iCloud 只读客户端。
- iOS 不渲染上游插件 SVG：当前 wire 只支持 providerIconName/tint 与 monogram，完整保留 Mac SVG 校验和显示；不向 iPhone 下发任意 XML。
- Menu Auto 的耗尽排序、Spend 布局项、设置 Back/Forward、Dock/睡眠与 stale WidgetExtension recovery 属 macOS 系统集成。
- iOS PreviewData 已有百分比、预算、generic details、进度行、多账号等卡片类型，本轮不为相同类型重复添加静态 provider 样例。新 provider 的真实形状由 Mac mock 与 bridge tests 覆盖。
- 账号级 local history 只附一位 active cost owner，不复制给每个 adapter 账号。Mobile 不承诺给来源未提供的每账号历史造出拆分值。

## Claude account-specific cost 的明确限制

Mac token account 的目录映射、扫描与账号切换完整保留；iOS 3.1仍按整台Mac保存成本历史，因此该目录的scoped cost不发送。启用映射时撤回该cost summary并提示在Mac查看；不会用scoped daily污染旧iOS的combined ledger。未映射的combined历史继续同步。此决定优先于表中通用“cost通道复用”描述。
